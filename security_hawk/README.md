Interactive multi-floor plan viewer and security monitoring hub for Home Assistant.

## About

Security Hawk turns your floor plans into an active security and automation operations center:
- **Interactive Multi-Floor Plans**: Draw walls, rooms, doors, windows, and import blueprint images (PNG, JPG, SVG, PDF).
- **Live Home Assistant State**: Real-time status for motion, contact sensors, doors with swing arcs, windows, lights, and climate.
- **Low-Latency Camera Feeds**: Integrated camera snapshot modals and live MJPEG streaming.
- **Spatio-Temporal Motion Trails**: Visual breadcrumb engine showing occupant movement sequences across rooms.
- **Multi-Building Site Overview**: 3D perspective roll-up of door openings, motion alerts, and sensor counts.
- **Compound Rules & Notifications**: "If X, Y, Z then Do" engine with alert dispatches to HA services, Email, WhatsApp, Discord, Slack, and Telegram.
- **Direct TV / Kiosk Display**: Dedicated unauthenticated port with access token for wall-mounted touchscreens and smart TVs.
